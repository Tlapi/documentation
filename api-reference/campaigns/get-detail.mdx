---
title: 'Get campaign detail'
api: 'GET https://api2.ecomailapp.cz/campaigns/{campaign_id}'
description: 'Returns detailed campaign information including statistics for sent campaigns.'
---

<ParamField path="campaign_id" type="integer" required>
  Campaign ID.
</ParamField>

The `smart_delivery` field returns the smart delivery settings of the campaign:

- `{"sending_policy_id": "..."}` when the campaign uses a sending policy,
- the manual limits (`priority_window_hours`, `priority_scope`, `frequency_cap_email_count`, `frequency_cap_email_days`, `frequency_cap_email_scope`) when they are set on the campaign,
- `null` when smart delivery is off.

See [Add new campaign](/api-reference/campaigns/add-new) for the meaning of each field.

<RequestExample>
```bash cURL
curl https://api2.ecomailapp.cz/campaigns/1 \
  -H "key: YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

```php PHP
$campaignId = 1;
$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, "https://api2.ecomailapp.cz/campaigns/{$campaignId}");
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'key: YOUR_API_KEY',
    'Content-Type: application/json',
]);
$response = curl_exec($ch);
curl_close($ch);
```
</RequestExample>
