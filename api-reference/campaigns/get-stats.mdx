---
title: 'Get campaign stats'
api: 'GET https://api2.ecomailapp.cz/campaigns/{campaign_id}/stats'
description: 'Returns aggregated statistics for a specific campaign.'
---

<ParamField path="campaign_id" type="integer" required>
  Campaign ID.
</ParamField>

<ParamField query="from_date" type="string">
  Filter statistics from this date onwards (`YYYY-MM-DD`, UTC).
</ParamField>

<ParamField query="to_date" type="string">
  Filter statistics up to this date (`YYYY-MM-DD`, UTC). Must be after `from_date`.
</ParamField>

When a date range is supplied (`from_date` and/or `to_date`), the response includes two additional fields alongside the lifetime totals:

- `opened_in_range` — unique opens that occurred within the selected period.
- `clicked_in_range` — unique clicks that occurred within the selected period.

<RequestExample>
```bash cURL
curl https://api2.ecomailapp.cz/campaigns/1/stats \
  -H "key: YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

```php PHP
$campaignId = 1;
$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, "https://api2.ecomailapp.cz/campaigns/{$campaignId}/stats");
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'key: YOUR_API_KEY',
    'Content-Type: application/json',
]);
$response = curl_exec($ch);
curl_close($ch);
```
</RequestExample>
