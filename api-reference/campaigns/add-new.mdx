---
title: 'Add new campaign'
api: 'POST https://api2.ecomailapp.cz/campaigns'
description: 'Create a new campaign.'
---

For list segments selection instead of a whole recipient list, use `"recepient_lists": {"segments": [{"id": "segment_id", "list": 14}]}`.
Segment IDs can be obtained from the [Show list detail](/api-reference/lists/show) endpoint.

Once smart delivery is set on a campaign, the response returns `recepient_lists` in the segments format, with the smart delivery settings inside the first segment. The segments format stays after you turn smart delivery off. Read the settings from the top-level `smart_delivery` field instead.

<ParamField body="title" type="string" required>
  Campaign title. Maximum 255 characters.
</ParamField>

<ParamField body="from_name" type="string">
  Sender's name. Maximum 150 characters.
</ParamField>

<ParamField body="from_email" type="string">
  Sender's email address.
</ParamField>

<ParamField body="reply_to" type="string">
  Reply-to email address.
</ParamField>

<ParamField body="subject" type="string">
  Campaign subject line. Maximum 255 characters.
</ParamField>

<ParamField body="html_text" type="string">
  HTML content of the campaign. When you send it, it must not be empty.
</ParamField>

<ParamField body="recepient_lists" type="array|object">
  Array of list IDs or an object with segments. See the example above for the segments format.
</ParamField>

<ParamField body="campaign_type" type="string" default="email">
  Campaign type. Allowed values: `email`, `sms`, `whatsapp`, `push_notification`. Your account must have the channel enabled, otherwise the request fails with `403`.
</ParamField>

<ParamField body="smart_delivery" type="object">
  Smart delivery settings of the campaign. Smart delivery skips subscribers who would receive too many emails.
  Send either `sending_policy_id`, or the manual limits. When you send `sending_policy_id`, the manual limits are ignored.
  When you omit `smart_delivery`, the campaign gets the default sending policy of your account.
  Send `null` or `{"sending_policy_id": "unlimited"}` to turn smart delivery off.

  <Expandable title="smart_delivery properties">
    <ParamField body="smart_delivery[sending_policy_id]" type="string">
      ID of a sending policy usable for campaigns. Use `standard` or `unlimited` for the system policies, or the ID of a custom policy from **Account settings** → **Settings** → **Sending rules**.
    </ParamField>

    <ParamField body="smart_delivery[priority_window_hours]" type="integer">
      Skip a subscriber who received an email in the last N hours. Allowed range: `0`–`24`. Requires `priority_scope`.
    </ParamField>

    <ParamField body="smart_delivery[priority_scope]" type="string">
      Which emails count for `priority_window_hours`. Allowed values: `all`, `campaigns`, `pipelines_all` (automations only).
    </ParamField>

    <ParamField body="smart_delivery[frequency_cap_email_count]" type="integer">
      Maximum number of emails a subscriber can receive in `frequency_cap_email_days` days. Allowed range: `1`–`50`. Send it together with `frequency_cap_email_days` and `frequency_cap_email_scope`.
    </ParamField>

    <ParamField body="smart_delivery[frequency_cap_email_days]" type="integer">
      Length of the frequency cap period in days. Allowed range: `1`–`7`.
    </ParamField>

    <ParamField body="smart_delivery[frequency_cap_email_scope]" type="string">
      Which emails count for the frequency cap. Allowed values: `all`, `campaigns`, `pipelines_all` (automations only).
    </ParamField>
  </Expandable>
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api2.ecomailapp.cz/campaigns \
  -H "key: YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "title": "Campaign title",
    "from_name": "Senders name",
    "from_email": "test@ecomailapp.cz",
    "reply_to": "test@ecomailapp.cz",
    "subject": "New campaign subject",
    "html_text": "HTML content of new campaign",
    "recepient_lists": [1],
    "smart_delivery": {
      "priority_window_hours": 12,
      "priority_scope": "all",
      "frequency_cap_email_count": 3,
      "frequency_cap_email_days": 7,
      "frequency_cap_email_scope": "campaigns"
    }
  }'
```
