---
title: 'Delete smart delivery rule'
api: 'DELETE https://api2.ecomailapp.cz/smart-delivery/rules/{id}'
description: 'Delete a custom smart delivery rule that no campaign or automation uses.'
---

<ParamField path="id" type="string" required>
  ID of the custom rule.
</ParamField>

<Note>
  System rules (`standard`, `unlimited`) cannot be deleted and return `403`.
  A rule used by a campaign or an automation action cannot be deleted. The `409` response lists the campaigns and automation actions that use it.
  A successful delete returns `204` with no body.
</Note>

<RequestExample>
```bash cURL
curl -X DELETE https://api2.ecomailapp.cz/smart-delivery/rules/aB3dE5fG7h \
  -H "key: YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

```php PHP
$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, 'https://api2.ecomailapp.cz/smart-delivery/rules/aB3dE5fG7h');
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_CUSTOMREQUEST, 'DELETE');
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'key: YOUR_API_KEY',
    'Content-Type: application/json',
]);
$response = curl_exec($ch);
curl_close($ch);
```
</RequestExample>
