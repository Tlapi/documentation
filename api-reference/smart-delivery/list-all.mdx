---
title: 'List smart delivery rules'
api: 'GET https://api2.ecomailapp.cz/smart-delivery/rules'
description: 'Return every smart delivery rule of the account — the two system rules first, then the custom rules.'
---

<ParamField query="applicability" type="string">
  Return only the rules usable in this area. Allowed values: `campaign`, `pipeline`, `both`. A rule with applicability `both` matches every filter value.
</ParamField>

<ParamField query="with_usages" type="boolean" default="false">
  Add the `usage` object to each rule — the campaigns and automation actions that use the rule. Without this parameter `usage` is `null`.
</ParamField>

<Note>
  Every account has two system rules: `standard` and `unlimited`. You can change the limits of `standard`, but not its name. You cannot change or delete `unlimited`.
</Note>

<RequestExample>
```bash cURL
curl -X GET "https://api2.ecomailapp.cz/smart-delivery/rules?applicability=campaign&with_usages=1" \
  -H "key: YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

```php PHP
$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, 'https://api2.ecomailapp.cz/smart-delivery/rules?applicability=campaign&with_usages=1');
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'key: YOUR_API_KEY',
    'Content-Type: application/json',
]);
$response = curl_exec($ch);
curl_close($ch);
```
</RequestExample>
