---
title: 'Get automation stats'
api: 'GET https://api2.ecomailapp.cz/pipelines/{pipeline_id}/stats'
description: 'Retrieve aggregate statistics for a specific automation.'
---

<ParamField path="pipeline_id" type="integer" required>
  Automation ID.
</ParamField>

<ParamField query="from_date" type="string">
  Filter statistics from this date onwards (`YYYY-MM-DD`, UTC).
</ParamField>

<ParamField query="to_date" type="string">
  Filter statistics up to this date (`YYYY-MM-DD`, UTC). Must be after `from_date`.
</ParamField>

When a date range is supplied (`from_date` and/or `to_date`), the response includes three additional fields alongside the lifetime totals:

- `open_in_range` — opens that occurred within the selected period.
- `click_in_range` — clicks that occurred within the selected period.
- `inject_in_range` — e-mails injected (sent) within the selected period.

<RequestExample>
```bash cURL
curl https://api2.ecomailapp.cz/pipelines/1/stats \
  -H "key: YOUR_API_KEY" \
  -H "Content-Type: application/json"
```

```php PHP
$ch = curl_init();
curl_setopt($ch, CURLOPT_URL, 'https://api2.ecomailapp.cz/pipelines/1/stats');
curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    'key: YOUR_API_KEY',
    'Content-Type: application/json',
]);
$response = curl_exec($ch);
curl_close($ch);
```
</RequestExample>
