Once you have the [remote MCP server](/ecomail-ai/remote-mcp) connected, you can talk to your Ecomail account in natural language. Here are some examples to get you started.

## Automations

<AccordionGroup>
  <Accordion title="List active automations">
    ```
    Show me all active automations with their triggered counts.
    ```
  </Accordion>
  <Accordion title="Automation performance">
    ```
    What are the stats for my welcome email automation? Show opens, clicks and unsubscribes.
    ```
  </Accordion>
  <Accordion title="Inspect automation steps">
    ```
    List all steps in my abandoned cart automation and show me the configuration of each step.
    ```
  </Accordion>
  <Accordion title="Top clicked links in an automation">
    ```
    Which links got the most clicks in my welcome automation?
    ```
  </Accordion>
</AccordionGroup>

## Building and editing automations

<Note>
  Editing works only on a stopped automation. Pause the automation in Ecomail first and start it again when you finish. A new automation is always created stopped.
</Note>

<AccordionGroup>
  <Accordion title="Create an automation">
    ```
    Create a welcome automation on my Newsletter list: send template "Welcome" right after signup, wait 3 days, then send template "Our bestsellers".
    ```
  </Accordion>
  <Accordion title="Change an email subject">
    ```
    In my welcome automation, change the subject of the first email to "Welcome aboard".
    ```
  </Accordion>
  <Accordion title="Change a wait">
    ```
    Change the wait before the second email in my welcome automation from 3 days to 5 days.
    ```
  </Accordion>
  <Accordion title="Insert a step">
    ```
    Add a 1-day wait between the trigger and the first email in my welcome automation.
    ```
  </Accordion>
  <Accordion title="Remove a step">
    ```
    Delete the tag step in my welcome automation and connect the steps around it.
    ```
  </Accordion>
  <Accordion title="Add a condition">
    ```
    After the first email in my welcome automation, add a condition for subscribers who opened any email in the last 30 days. If yes, end the automation. If no, send template "Reminder".
    ```
  </Accordion>
  <Accordion title="Change when an automation starts">
    ```
    Change the daily trigger of my win-back automation to 9:30.
    ```
  </Accordion>
  <Accordion title="Limit an automation to a segment">
    ```
    Make my win-back automation start only for the subscribers in my "VIP" segment.
    ```
  </Accordion>
</AccordionGroup>

## Segments

<AccordionGroup>
  <Accordion title="See what a segment contains">
    ```
    Show me the exact conditions of my "VIP" segment in the Newsletter list.
    ```
  </Accordion>
  <Accordion title="Create a segment">
    ```
    Create a segment in my Newsletter list of subscribers who did not open any email in the last 90 days.
    ```
  </Accordion>
  <Accordion title="Change a segment">
    ```
    Change my "Inactive" segment to subscribers who did not open any email in the last 60 days.
    ```
  </Accordion>
  <Accordion title="Rename a segment">
    ```
    Rename my "VIP" segment to "VIP customers".
    ```

  A changed segment applies immediately to every campaign and automation that uses it. Ask the assistant to show you the current conditions first.
</Warning>

## Multi-step analysis

These examples combine multiple tools in a single conversation to get deeper insights.

<AccordionGroup>
  <Accordion title="Campaign ROI analysis">
    ```
    I want to understand ROI of my email campaigns.
    1. Show me the conversion analytics for campaigns only, last 90 days
    2. List the top 5 campaigns by send date in that period
    3. For each campaign, show the open rate and click rate
    Summarize which campaign drove the most revenue.
    ```
  </Accordion>
  <Accordion title="Customer health check">
    ```
    Do a health check for subscriber john@example.com:
    - What lists are they on and what are their tags?
    - Show their recent email engagement (opens, clicks)
    - What automations have they been through?
    - What are their recent purchases?
    Give me an overall summary of this customer's engagement.
    ```
  </Accordion>
  <Accordion title="Monthly performance report">
    ```
    Create a monthly performance summary for February 2026:
    - How many campaigns were sent and what were the average open/click rates?
    - What were the conversion numbers (purchases, revenue, avg order value)?
    - How does deliverability look?
    - What are the top 5 products by revenue?
    Format it as a report I can share with my team.
    ```
  </Accordion>
</AccordionGroup>

## Templates

<AccordionGroup>
  <Accordion title="Browse templates">
    ```
    List my email templates and find any that contain "newsletter" in the name.
    ```
  </Accordion>
  <Accordion title="Create a template">
    ```
    Create a new HTML email template called "March Newsletter" with a clean, responsive layout
    that includes a header image, intro paragraph, 3 content blocks and a footer with social links.
    ```
  </Accordion>
  <Accordion title="Duplicate and modify">
    ```
    Duplicate my "Welcome Email" template so I can use it as a starting point for a new version.
    ```
  </Accordion>
  <Accordion title="Edit a template">
    ```
    In my "Spring sale" template, change the headline to "Last days of the sale" and keep everything else.
    ```
  </Accordion>
  <Accordion title="Use your own image">
    ```
    Upload https://www.example.com/images/logo.png to my file manager and use it as the header image in my "Spring sale" template.
    ```
  </Accordion>
</AccordionGroup>

<Note>
  Images must be available at a public URL that returns a PNG, JPG or GIF directly. The assistant cannot read files from your computer.
</Note>
